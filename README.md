# 个人艺术家作品集

无需安装依赖的静态网站。所有作品和插画均为明确标注的示例；没有虚构个人履历或联系方式。

## 如何打开

下载整个项目文件夹后，直接双击 `index.html`，用 Chrome、Edge、Firefox 或 Safari 打开即可。图片和脚本都在本地，无需联网。

也可以在项目文件夹中运行 `python3 -m http.server 8000`，再在浏览器地址栏输入 `http://localhost:8000`。按 Ctrl+C 停止服务。直接双击打开不需要 Python。

## 文件说明

- `index.html`：页面结构、艺术家名称、简介、理念、研究、展览经历。
- `style.css`：颜色、字体、留白、电脑和手机布局。
- `data.js`：集中保存作品标题、年份、材料、尺寸、系列、图片路径、描述，以及邮箱和 Instagram 链接。
- `script.js`：系列筛选、作品详情弹窗、上一件/下一件、手机导航和联系方式显示。
- `images/`：随网站附带的本地 SVG 占位插画，无需外部图片服务。

## 替换为自己的内容

1. 用文本编辑器打开 `index.html`，搜索“你的名字”，替换页头、页面标题和页脚；替换简介、理念、研究和展览经历占位文字。
2. 将自己的作品图片放进 `images/`，例如 `my-painting.jpg`。打开 `data.js`，将对应 `image` 改成 `images/my-painting.jpg`，并填写真实作品资料及 `alt` 图片描述。每件作品的 `id` 必须唯一。
3. 首页代表作使用第一件作品的示例图片和文字；更换时同步修改 `index.html` 中 `.hero-image` 的图片、说明文字、`data-open` 作品 ID 以及图片的 `alt`。
4. 在 `data.js` 的 `contact` 中填写你愿意公开的邮箱与完整 Instagram HTTPS 链接；留空则显示“待填写”，不会产生假链接。
5. 复制作品对象可以增加作品，系列筛选会自动更新。替换真实资料后，删除页面与脚本中适用的“示例/占位”提示；不要在示例图片仍被使用时取消其标注。
6. 保存后刷新浏览器。检查首页、所有导航、系列筛选、作品详情、联系链接，并缩窄窗口检查手机布局。

点击作品可查看大图；弹窗内可切换作品，键盘左右方向键也可切换，Esc 可关闭。手机上的“菜单”按钮展开导航。

本项目未部署到互联网，没有收集访客数据的表单、统计代码或外部字体。发布前请确认文字、图片版权及希望公开的个人资料。
